# Control de Gastos - C#

Proyecto de consola desarrollado en **C# con Visual Studio**.

---

##  Descripción

Este proyecto permite:

- Ingresar múltiples gastos desde consola
- Guardar los gastos en memoria
- Mostrar un historial de gastos
- Calcular el total acumulado

---

##  Tecnologías utilizadas

- C#
- .NET Console
- Visual Studio Community
- Git & GitHub

---

## 🧩 Estructura del código

El programa está organizado en varios métodos:

### 🔹 Main
Punto de entrada del programa. Coordina la ejecución general:
- Inicializa el arreglo de gastos
- Llama a los métodos principales

---

###  CapturarGastos
- Solicita gastos al usuario
- Guarda los valores en un arreglo
- Suma el total
- Usa un bucle `while`

---

###  MostrarHistorial
- Recorre los gastos con un `for`
- Imprime cada gasto registrado

---

###  MostrarTotal
- Muestra el total acumulado
